# Job Market Analysis

## Project Overview
This project analyzes job market trends using Excel, Python, and Power BI. 
The analysis focuses on salary trends, job distribution by country, and salary comparisons across seniority levels.

## Tools Used
- Excel
- Python
- Power BI
- Pandas
- Matplotlib

## Key Insights
- Senior-level roles showed the highest average salaries.
- Job opportunities were concentrated in specific countries.
- Salary distribution varied across job titles and seniority levels.
